# Customer Segmentation using RFM Analysis

## 📊 Project Overview

This project focuses on customer segmentation and behavioral analysis using the **RFM (Recency, Frequency, Monetary) methodology** in Tableau.

The goal is to analyze customer purchasing behavior, rank customers based on their RFM scores, and identify different customer segments.

## 🔍 RFM Analysis

- **Recency:** How recently a customer made a purchase
- **Frequency:** How often a customer made a purchase
- **Monetary:** How much a customer spent

Customers are segmented into four groups:

- **Loyal**
- **Active**
- **New**
- **Lost**

## 📈 Dashboard

An interactive Tableau dashboard was created to analyze and compare customer behavior across different RFM segments.

The dashboard includes:

- RFM Customer Analysis
- Sales Analysis
- Monetary Analysis
- Frequency Analysis
- RFM Score
- Customer Ranking
- Customer Segmentation

## 🛠 Tools & Technologies

- Tableau
- Microsoft Excel
- RFM Analysis
- Data Visualization
- Customer Segmentation

## 🎯 Project Goal

The main objective is to identify valuable customer segments and provide insights that can support targeted marketing strategies and customer retention decisions.
